# Retail Performance Insights
Transforming retail transaction data into actionable business insights through interactive Excel analytics.

## About

Analyzed retail data to identify sales, profit, regional, category, discount, and yearly performance trends using Microsoft Excel.

## Tools

Excel | PivotTables | PivotCharts | Slicers | Data Visualization

## Key Insights

* Identified top-performing regions and product categories
* Analyzed sales and profit trends
* Evaluated discount patterns
* Developed an interactive KPI dashboard
